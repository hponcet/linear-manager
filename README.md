# linear-manager
VSCode extension to manage linear issues with git

## Features

This extension helps you manage Linear issues directly from VS Code, with git integration using simple-git.

## Requirements

- VS Code 1.85.0 or higher
- Node.js and npm

## Installation

1. Clone this repository
2. Run `npm install` to install dependencies
3. Press F5 to run the extension in debug mode

## Development

- Run `npm run lint` to lint the code

## Dependencies

- [simple-git](https://www.npmjs.com/package/simple-git) - Git integration library
